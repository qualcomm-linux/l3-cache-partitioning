# Maintainers

## Project Maintainers

The l3-cache-partitioning project maintainers are responsible for:

- Reviewing and merging pull requests
- Triaging issues and bug reports
- Maintaining code quality and architectural consistency
- Managing releases and kernel-version compatibility
- Responding to security vulnerability reports
